# Curso de Analítica de Datos con Python — Universidad Icesi

## Para quién es

Para profesionales de cualquier área que quieren aprender a analizar datos con Python para tomar mejores decisiones. No se requiere experiencia en programación: el curso parte desde cero y llega a análisis exploratorio, visualización e introducción al machine learning.

## Qué hace diferente

- Modalidad 100% virtual con sesiones en vivo y grabaciones disponibles.
- 40 horas intensivas con proyectos prácticos desde la primera semana.
- Instructores con experiencia en ciencia de datos aplicada a empresas colombianas.
- Entorno de trabajo en Google Colab (sin instalaciones locales).
- Certificado Icesi al completar el curso y el proyecto final.

## Contenido del curso

1. Fundamentos de Python para análisis de datos.
2. Pandas y NumPy para manipulación de datos.
3. Visualización con Matplotlib y Seaborn.
4. Análisis exploratorio de datos (EDA).
5. Introducción a modelos predictivos con Scikit-learn.
6. Proyecto final: análisis de datos reales con presentación de hallazgos.
